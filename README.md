# 🧠 AI-Powered Brain Tumor Detection & Analysis System

## 📌 Overview

The AI-Powered Brain Tumor Detection & Analysis System is a deep learning-based web application that classifies brain MRI scans into four categories:

* Glioma
* Meningioma
* Pituitary Tumor
* No Tumor

The project uses EfficientNetB0 for image classification and Grad-CAM (Gradient-weighted Class Activation Mapping) for explainable AI, allowing users to visualize the region that influenced the model's prediction.

The application provides confidence scores, risk assessment, prediction history tracking, and professional PDF report generation.

## 🧠 Model Details

Model: EfficientNetB0

Framework: TensorFlow / Keras

Input Size: 224 × 224 × 3

Optimizer: Adam

Loss Function: Categorical Crossentropy

Epochs: 20

Transfer Learning: Yes
